# Repo File Manager

তোমার একটা নির্দিষ্ট GitHub রেপোর জন্য bulk delete + zip-extract-upload + rename — একটা Cloudflare Worker হিসেবে ডিপ্লয় হয়, GitHub টোকেন সবসময় সার্ভার সাইডে (Worker secret) থাকে, ব্রাউজারে কখনো যায় না।

## যেভাবে কাজ করে

- Worker-এ দুটো এন্ডপয়েন্ট: `GET /api/tree` (রেপোর সব ফাইল লিস্ট করে) আর `POST /api/commit` (add/delete/rename — যেকোনো কম্বিনেশন — একটা মাত্র কমিটে পুশ করে, GitHub-এর Git Data API দিয়ে)
- ফ্রন্টএন্ড একটাই static HTML পেজ, `public/index.html` — zip এক্সট্র্যাকশন ব্রাউজারেই হয় (fflate লাইব্রেরি দিয়ে), Worker-এ শুধু তুমি যেসব ফাইল সিলেক্ট করেছ সেগুলোই যায়
- Worker-এর নিজস্ব একটা পাসওয়ার্ড থাকে (`ACCESS_PASSWORD`) — এটা ছাড়া `/api/*` এন্ডপয়েন্ট কেউ কল করতে পারবে না

## সেটআপ

### ১. GitHub-এ একটা fine-grained Personal Access Token বানাও

GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token

- **Repository access**: শুধু ওই একটা রেপো সিলেক্ট করো (all repos না)
- **Permissions**: শুধু **Contents: Read and write** দাও, আর কিছু লাগবে না
- টোকেনটা কপি করে রাখো (একবারই দেখাবে)

এই টোকেন শুধু ওই একটা রেপোতেই কাজ করবে, তোমার পুরো অ্যাকাউন্টে না — এটাই সবচেয়ে নিরাপদ অপশন।

### ২. কনফিগার করো

`wrangler.jsonc`-এ এই দুটো লাইন বদলাও:

```jsonc
"vars": {
  "GITHUB_OWNER": "তোমার-github-username",
  "GITHUB_REPO": "রেপোর-নাম",
  "GITHUB_BRANCH": "main"
}
```

### ৩. Secrets সেট করো

```bash
npm install -g wrangler   # না থাকলে
wrangler login

wrangler secret put GITHUB_TOKEN
# পেস্ট করো ধাপ ১-এর টোকেন

wrangler secret put ACCESS_PASSWORD
# একটা পাসওয়ার্ড দাও, এটা দিয়েই টুলে লগইন করবে
```

### ৪. (ঐচ্ছিক কিন্তু সুপারিশকৃত) Brute-force লকআউট চালু করো

পাসওয়ার্ড কেউ বারবার ভুল দিয়ে গেস করার চেষ্টা করলে সেই IP-কে সাময়িকভাবে ব্লক করে দিতে একটা KV namespace লাগবে:

```bash
wrangler kv namespace create RATE_LIMIT
```

এটা একটা `id` দেবে — সেটা `wrangler.jsonc`-এর `kv_namespaces` অংশে বসাও। এই ধাপ স্কিপ করলেও Worker চলবে, শুধু লকআউট চেক অফ থাকবে — তাই প্রোডাকশনে এটা করে নেওয়া ভালো।

লকআউট যেভাবে কাজ করে: প্রতি IP-তে ৫ বার ভুল পাসওয়ার্ড দিলে ৩০ সেকেন্ডের ব্লক শুরু হয়, তারপর প্রতিবার ভুল দিলে সময় দ্বিগুণ হয়ে সর্বোচ্চ ১৫ মিনিট পর্যন্ত যায়। সঠিক পাসওয়ার্ড দিলে কাউন্টার রিসেট হয়ে যায়। ফ্রন্টএন্ডেও একটা কাউন্টডাউন দেখানো হয়, কিন্তু আসল প্রোটেকশন এই Worker-সাইড KV চেকটাই — ফ্রন্টএন্ডের কাউন্টডাউন কেউ ব্রাউজার বাইপাস করে সরাসরি Worker-এ রিকোয়েস্ট পাঠালে থামাতে পারবে না।

### ৫. ডিপ্লয়

```bash
wrangler deploy
```

Wrangler একটা URL দেবে (যেমন `github-file-manager.<তোমার-subdomain>.workers.dev`) — সেটাতে গিয়ে পাসওয়ার্ড দিয়ে ঢুকে পড়ো।

### পাসওয়ার্ড রিসেট করতে চাইলে

```bash
wrangler secret put ACCESS_PASSWORD
```
আবার চালিয়ে নতুন পাসওয়ার্ড পেস্ট করলেই পুরনোটা বদলে যাবে — কোনো আলাদা "reset" ফ্লো নেই, এটাই একমাত্র ও সরাসরি উপায়। বদলানোর পর ব্রাউজারের সেশন থেকেও আগের পাসওয়ার্ড মুছে ফেলতে "Sign out" চাপলেই হবে।

### GitHub টোকেন কীভাবে নিরাপদে অ্যাড হয়

- টোকেন `wrangler secret put GITHUB_TOKEN` দিয়ে সেট হয় — এটা Cloudflare-এর এনক্রিপ্টেড secret store-এ থাকে, কখনো `wrangler.jsonc`-এ প্লেইনটেক্সটে লেখা হয় না, আর ব্রাউজারেও কখনো পাঠানো হয় না (ফ্রন্টএন্ড শুধু `ACCESS_PASSWORD` জানে, `GITHUB_TOKEN` না)।
- টোকেন বানানোর সময় **Fine-grained** টাইপ বেছে, শুধু ওই একটা রেপো সিলেক্ট করলে — এটা leak হলেও ক্ষতি ওই একটা রেপোতেই সীমাবদ্ধ থাকে, বাকি অ্যাকাউন্ট অক্ষত থাকে।
- টোকেন কখনো রোটেট (বদলাতে) করতে চাইলে GitHub-এ পুরনোটা revoke করে নতুন একটা বানিয়ে আবার `wrangler secret put GITHUB_TOKEN` চালালেই হবে।

## জেনে রাখা ভালো

- **Cloudflare ফ্রি প্ল্যানে** প্রতি রিকোয়েস্টে সর্বোচ্চ ৫০টা subrequest (অর্থাৎ GitHub API কল) করা যায়। প্রতিটা নতুন ফাইল অ্যাড করতে একটা করে কল লাগে (রিনেমে লাগে না — সেটা বিদ্যমান blob-ই রিইউজ করে)। তাই একসাথে ~৪০+ নতুন ফাইলের বেশি একটা zip থেকে পুশ করতে চাইলে **Workers Paid প্ল্যান** ($৫/মাস) লাগবে — সেখানে লিমিট ১০,০০০। ছোট ছোট ব্যাচে ভাগ করেও কাজ চালানো যায়।
- একবারে একজনের ব্যবহারের জন্য বানানো (personal tool) — টিমের জন্য শেয়ার করতে চাইলে পাসওয়ার্ড-ভিত্তিক অথ-এর জায়গায় আরও শক্তপোক্ত কিছু (যেমন Cloudflare Access) বসানো ভালো।
- কমিট সবসময় `GITHUB_BRANCH`-এ সরাসরি যায় (কোনো PR তৈরি হয় না) — ইচ্ছাকৃতভাবে সহজ রাখা হয়েছে, PR ফ্লো লাগলে বলো, যোগ করে দেওয়া যাবে।
